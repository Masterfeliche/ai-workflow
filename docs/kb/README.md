# Project Knowledge Base

These files are the project-local knowledge source. They are not the shared/global UEKB service.

- `DEVELOPMENT_GUIDE.md`: verified local development and test commands.
- `GOTCHAS.md`: non-obvious behavior, workarounds and evidence.
- `TECHNOLOGY_MAP.md`: detected stack and learning bridges.
- `KNOWLEDGE_MODEL.md`: record structure, scopes and relationships.
- `KNOWLEDGE_GOVERNANCE.md`: approval, provenance, freshness and access.
- `RETRIEVAL_CONTRACT.md`: model-neutral REST/MCP/export retrieval contract.

Keep project-specific facts scoped to this repository/project. Shared global records require
separate review and must not expose confidential project information.
